## 先说五个关键事实

1. **正式中文名是《历史巨轮：人类文明新篇章》**，一刻馆与 CGE 合作出版，2016 年发行，盒子 25.5 × 36.5 × 7.0 cm。
   - 扩展的中文名是《历史巨轮：新领袖&新奇迹》，一刻馆 2020 年众筹，同时出了典藏版大盒。
   - 玩家叫它“历史巨轮”或“TTA”。老版（2006）是港版《歷史巨輪》，已绝版。
2. **CGE 官网有官方简中规则书、玩家手册和快速参考**，用词以这三份为准：内政行动点、卡牌列、黄色人口区、蓝色供给区、阵型（不叫战术）、条约（不叫协定）、地区牌、体面退出。
   - 三份都是图片 PDF，讲规则页的截图可以直接用简中版。
   - **扩展没有简中规则书**，只能依据英文版。
3. **官方没有 FAQ 和勘误**。官方澄清只有三处：规则书 p12 的卡牌附录、扩展规则书 p3 和 p6，以及 BGG 上 1 条 CGE 的回复。社区问题大多是老玩家回答的，常见问题里会标“非官方”。
4. **线下最繁琐、最易错的环节**（BGG 和 B 站一致）：
   - 回合末结算：腐败 → 生产食物 → 消耗食物 → 生产资源，以及饥荒、起义、蓝色标记找零；
   - 每回合补卡牌列：2 / 3 / 4 人分别移除前 3 / 2 / 1 格；第一轮特殊；
   - **时代转换的清理**：每人失去 2 个黄色标记，过时的手牌、领袖、未完成奇迹、条约要移除。版图上没画时代 III 的这一步，经常忘；
   - 什么时候进入最后一轮；
   - 事件牌堆换堆：用完时把未来事件洗混，按时代排序；
   - 终局时代 III「影响」类事件计分。

   另外，很多人先玩官方 App 再玩实体。**App 有几条规则和纸版不同**：殖民竞拍改成暗标，事件在受影响玩家回合开始时结算，富饶之地 I 是 6 资源（纸版 5）。从 App 转来的新手容易照 App 玩。
5. **时长**：BGG 老手约每人 45 分钟。首局 4 个新人有多例报告 7–9 小时。
   - 官方玩家手册的主体就是「**第一局简化玩法**」：不玩时代 III，不互相攻击，有自己的一套终局计分。这和本系列“带新人快速开局”的定位最贴合。

## 不做

| 项目 | 理由 |
|---|---|
| 电子玩家版图：资源、工人、蓝黄标记、行动点 | 实体版图本身就是记录器，搬到手机等于做数字版；官方 App 已经有了 |
| 文化、科学、军力的分数轨和增速记录 | 版图上已有；每回合要人人同步输入，负担比收益大。BGG 只有桌子太小的人提过 |
| 回合末结算计算器（输入库存，输出腐败、消耗） | 新版设计成看版图最左边露出的负数就能读出；输入成本比看版图还高。只做顺序速查 |
| 卡牌列、手牌、军事牌、事件牌堆的逐张记录 | 是游戏本体；军事牌还是隐藏信息 |
| 殖民竞拍、条约谈判 | 面对面互动是线下的乐趣 |
| 扩展混合模式的随机抽牌 | 官方做法是实物洗牌抽，代理牌已经解决公开混合；清单只写步骤 |
| 单卡图鉴（领袖、奇迹、事件逐张） | 卡多（基础 + 扩展上百张），有版权和翻译问题；高频卡问题放进常见问题 |
| 中途存档 | 要录入整个版图；常见问题里只写“每人拍照，记下事件牌堆顺序” |
| 每步计时、棋钟 | 玩家自己的家规 |
| 老版（2006）规则、单人机器人 | 只做新版；新老差异写进常见问题。单人只有 App 和玩家自制规则 |

## 要用户拍板

1. **扩展做到哪一步**：
   - A（推荐）：开局清单和常见问题包含扩展，讲规则页只讲基础。扩展没有简中规则书，扩展相关用词依据英文规则书自己译，并标出。
   - B：只做基础游戏。
2. **完整版终局计分要时代 III 事件卡的数据**：每张卡怎么计分（例如“科学影响 14/7/0”）。官方规则书没有卡表。
   - A（推荐）：你手边如果有实体版，把时代 III 军事牌里的事件拍给我，按实物录入，用词和简中版一致；
   - B：我从 BGG 卡牌图和官方资料整理，核对不到的卡不放，页面注明“按英文卡面整理”；
   - C：完整版只做“逐张输入文化分”的手动加总，不内置卡表。
3. **一个数值待核实**：黄色人口区最左边两段的消耗数值，在所有官方图里都被方块挡住了。速查页只写“看最左边露出的负数”，不写具体数字；如果你有实体版图，拍一张空版图就能补上。
4. **GitHub 仓库**：现在建 `86777835/through-the-ages-helper`（public，分支 main），先把调研文档和这份清单推上去？
5. **上线**：开发完是否直接部署？Worker 名 `through-the-ages-helper`，子域名 `tta.leisurecat.cloud`，rate limit namespace 1171。不同意的话，做完再问。
